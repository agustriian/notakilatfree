CATATAN OFFLINE
Aplikasi tidak membutuhkan server/database online untuk fungsi lokal. Data nota dan profil disimpan di perangkat pengguna menggunakan localStorage. Service worker digunakan untuk mode PWA/offline saat aplikasi dijalankan melalui hosting lokal/web yang mendukung service worker.


VERSI V12 - VERCEL

- Tidak membutuhkan Netlify.
- Data tetap offline/localStorage di perangkat pengguna.

CATATAN GITHUB / KEAMANAN
- Project ini adalah static/offline web app. Source JavaScript dapat dibaca oleh siapa pun jika repository GitHub dibuat public.
- Jangan menyimpan API key, password, token, credential, atau secret server di source code.
- Fitur lock FREE/PRO pada client-side adalah pembatas UI, bukan sistem lisensi yang aman. Pengguna teknis dapat memodifikasi JavaScript.
- Untuk menjaga source code tetap privat, gunakan GitHub repository PRIVATE. Vercel tetap dapat melakukan deployment dari repository private.
- PIN toko sekarang berasal dari pengaturan lokal pengguna, bukan hardcoded secret di source code.
